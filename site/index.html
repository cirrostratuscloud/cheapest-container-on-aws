cheapo

Cheapest possible always-on public container on AWS. Proof of concept.

This page is served by an nginx container on Fargate, reached through:

Internet -> API Gateway HTTP API (pay per request) -> VPC Link (no NLB, no hourly fee) -> Cloud Map service (ECS service discovery) -> Fargate task, ARM64 + Spot (private dual-stack subnet, IPv6 egress)

No NAT gateway. No load balancer. No PrivateLink endpoints.

Monthly cost @ 1,000 page views

us-east-1. Task = 0.25 vCPU / 0.5 GB, running 24/7 (~730 hrs). Cost is driven by container uptime, not traffic — 1,000 views is rounding error.

For comparison: ARM on-demand Fargate ≈ $7.7/mo; x86 on-demand ≈ $9.5/mo. A NAT gateway alone would add ~$32/mo, and a load balancer ~$16/mo — both avoided here.

ARM Spot multipliers: ×0.8 = ~20% Graviton discount, ×0.3 = up to ~70% Spot discount. Spot tasks can be reclaimed with a 2-minute warning; fine for a single-instance demo blog.
